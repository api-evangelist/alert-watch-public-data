# Alert Watch Public Data — not listed

This repository is a removal notice. It is **not listed** in the APIs.io catalog, and is
kept only so inbound links do not dangle.

## Why

Every declared surface — base URL, documentation URL, OpenAPI, and llms.txt — lives on
`fablgen-agent.github.io`. There is no owned domain anywhere in the record.

The APIs.io listing standard allows individual artifacts to live on GitHub, but requires
a valid domain at the root of the information. This submission has none.

All URLs resolved normally at review. **This is not a dead-service removal** — it is a
listing-standard one.

Separately, the service is a re-publication rather than an API program: read-only static
JSON snapshots derived from GOV.UK Emergency Alerts pages and the GDACS API. That data
belongs to third parties who publish it themselves.

## Coming back

Recorded as `catalog-hygiene` with `relisting: standard`. Nobody asked for the removal
and nothing was taken from anyone. **If the same service is published from an owned
domain, it re-enters through the normal harvest at no charge.**
